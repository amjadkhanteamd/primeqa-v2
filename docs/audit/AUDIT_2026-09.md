## 1. Why this audit exists, and what it was told to hunt

No human has used the product for a task. Every verification to date proved
what it thought to test, and every recent defect was a data shape nobody
planned. The brief named the system's characteristic failure — **a control that
reports its own correctness** — and gave four instances (the read-only guard,
the repair gate reading the LLM's confidence, the audit-less schedule toggle,
the batching comment the code lacked). It asked for the fifth.

**Found: AUD-008.** The requirement page's readiness handler is commented
"never breaks the page". Its `except` clause calls `logging.getLogger`, and
`logging` is not imported in `views.py`, so the safety net raises `NameError`
exactly when it is needed. Every day the net is not exercised, the comment
reads as true. Four more findings are members of the same class (§4).

## 2. Method

Sessions were four minted users on a scratch copy — viewer, member and admin of
tenant 1, member of a fresh tenant 2 — with CSRF primed like a browser, so a
POST proves the route's gate and not the CSRF layer. Production was touched
only by read-only GETs under the server-side read-only connection option, and
that guard was **proven before every production read** by attempting `CREATE
TABLE`, `INSERT` and `UPDATE` (each refused with `ReadOnlySqlTransaction`).

The tooling itself is in `scripts/audit/` and was built to distrust
self-reports:

| tool | what it does, and the self-report it replaces |
|---|---|
| `inventory.py` | route census from the LIVE `url_map`, not the AST — the AST oracle misreads aliases (AUD-001) |
| `deadlinks.py` | every `href`, `action`, `hx-*`, `data-*` and `fetch()` target resolved against the live map, Jinja collapsed, `{% if %}` branches expanded — the unit sweep skipped every parameterised href (AUD-002) |
| `render.py` | every GET route rendered per session; asserts a `<main>` with text, the nav hooks, and never the 500 page; a fresh client per request because `/logout` poisoned the first run |
| `post_all.py` | every write route × session × five hostile bodies (empty, maximal, wrong-type, missing-CSRF, missing-required) |
| `session.py` | the minted sessions and CSRF priming |
| `ledger.py` | append-only findings with the brief's fields; `findings.json` is written from it |

Two of my own tools misreported during the audit and were caught by their own
evidence: a scripted edit that printed "applied" having matched nothing, and a
`pyflakes` run that reported zero undefined names because pyflakes was not
installed. Both are recorded here because they are the failure class under
audit, in the auditor.
