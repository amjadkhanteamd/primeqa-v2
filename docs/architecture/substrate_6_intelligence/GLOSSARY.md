# Substrate 6 — Observation & Interpretation — Glossary

Terms specific to substrate-6.

---

**Interpretation.** S6's structured output for one run: the run identity, the `outcome` (carried verbatim from S4), a semantic `verdict`, a deterministic `attribution`, `evidence_refs`, and (after `attribute_run`) a structured `Cause`. Reviewable / editable / versionable — the S2-claim lifecycle discipline, one substrate up.

**Verdict.** The semantic classification of what an outcome *means* for the requirement: `prohibition_enforced` / `prohibition_not_enforced` / `rejected_unasserted_reason` (behavioral); `asserted_metadata_present` / `asserted_metadata_absent` (inspection); `not_evaluated` (errored).

**Attribution.** The deterministic, evidence-derived explanation (what + why) — never generated by an LLM. Prose bound to the evidence.

**Cause / cause_kind.** The structured deeper-attribution attached by `attribute_run` to a failed behavioral verdict. `cause_kind` ∈ `vr_inactive` · `vr_formula_drift` · `vr_formula_indeterminate` · `no_active_vr` · `enforcement_gap` · `other_vr_fired` · `platform_constraint`. The machine-structured companion to the prose attribution (clusterable downstream).

**evidence_refs.** Pointers (`step_id` + detail) into the interpreted `RunEvidence` backing a claim of the attribution — auditable provenance, not a copy.

**`S1VrReader` port.** The read-port through which `attribute_run` reads a subject Object's validation rules — the inter-substrate read-through pattern (S6-3): production delegates to S1's query interface (`SemanticOrgModel`), never raw S6-local SQL over S1's tables.

**evaluate (consumed).** The neutral `formula.evaluate` primitive (S1-semantic package, built for S8 in D-113). Since D-114, S6's `_attribute_not_enforced` consumes it (off S3's `derive`) for the precise "does the payload still violate the current formula?" check — parallel-siblings with S8 (S6 post-run, S8 pre-run), never S6 → S8.

**Eager + best-effort.** The interpret stage runs in the S4 run-path right after `finalize_run`, inside a `begin_nested()` savepoint: a softer S6 failure rolls back to the savepoint while the S4 run truth survives and commits (`RunPathResult.interpretation = None`). Evidence-first.

**Deterministic-first.** The interpreter attributes from the evidence with no LLM; LLM phrasing + cross-run clustering are deferred additive layers that phrase / aggregate the deterministic core, never produce the attribution.
